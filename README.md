# Catálogo de Encomendas

Projeto React + Vite pronto para catálogo com encomenda direta por WhatsApp.

## Como correr no computador

```bash
npm install
npm run dev
```

## Como colocar online grátis no Vercel

1. Criar conta no GitHub
2. Criar repositório novo
3. Fazer upload destes ficheiros
4. Ir ao Vercel
5. Importar o repositório
6. Carregar em Deploy

## Personalização rápida

No ficheiro `src/App.jsx` podes alterar:

- `WHATSAPP_NUMBER`
- `COMPANY_NAME`
- `DELIVERY_DAYS`
- `SERVICE_AREAS`
- `PRODUCTS`
